zbValueSlider

Portable value-curve slider — one dependency-free JS file (assets/value-slider.js, styles self-inject). 1–6 value anchors with labels; the track is an area chart of the values (span-zoomed over a value floor), the handle snaps to the nearest anchor, and the headline reveals the snapped value. A single anchor renders as a locked, fully-filled static display.

4 anchors — the Cash Value Report configuration

drag the handle, or use arrow keys

6 anchors — the maximum

2 anchors — the minimum interactive

1 anchor — static: locked centered handle, full chart, no end labels

Themed via CSS variables (2 anchors)

Set --zvs-cta / --zvs-lo / --zvs-hi / --zvs-track / --zvs-dot / --zvs-ink / --zvs-muted on the container or any ancestor.

Colors defined in the script call (3 anchors)

Pass a colors object — handle / fillLo / fillHi / track / dot. Script colors win over CSS variables.

Usage

<div id="mySlider"></div>
<script src="value-slider.js"></script>
<script>
  var slider = zbValueSlider(document.getElementById("mySlider"), {
    anchors: [                        // 1-6 entries; sorted by value for you
      { value: 312000, label: "Quick cash close" },
      { value: 371000, label: "Top market value" }
    ],
    format:   function (v) { return "$" + v.toLocaleString(); }, // optional
    headline: true,                   // big number/range above the track
    endLabels: true,                  // min/max labels under the track
    onSelect: function (anchor, index) { console.log(anchor.value); },
    colors: {                         // optional; script wins over CSS vars
      handle: "#128A46", fillLo: "#BFE8CF", fillHi: "#128A46",
      track: "#E8EFE9", dot: "#6E9B7F"
    }
  });
  slider.snapTo(1);                   // programmatic snap (0-based)
</script>
