Publisher Link Specification

How to build links into the zBuyer home-value funnel: your assigned campaign IDs plus the optional pre-population fields that carry your consumer's details into the form.

Link structure

Your campaign parameters, then any prepop fields, all standard URL querystring format.
{BASE_URL}?mid={YOUR_MID}&affid={YOUR_AFFID}&zfname=...&zlastname=...&zphone=...&zemail=...&zstreet=...&zcity=...&zstate=...&zzipcode=...

The base URL and your mid / affid values are assigned by your zBuyer account contact. Every link must carry both.

Campaign parameters

ParameterRequiredDetails
midrequiredYour campaign ID (also called MID), assigned by zBuyer. Identifies the campaign for attribution and payout.
affidrequiredYour affiliate / sub-source ID, assigned by zBuyer. Use it to segment your own placements if you run more than one.

Pre-population fields

All optional — send whichever details the consumer has already provided to you. Prepopped fields appear in the form ready to confirm; the address verifies automatically against USPS data and displays formatted.
ParameterFormatDetails
zfnametextConsumer's first name.
zlastnametextConsumer's last name.
zphone10 digitsNumbers only, no punctuation — e.g. 6238805511. Displays formatted.
zemailemailURL-encode the @ as %40.
zstreettextStreet address only (no city/state/zip in this field). Encode spaces as + or %20 — e.g. 1401+Candlewood+Dr.
zcitytextCity.
zstate2 lettersUSPS state code — e.g. PA.
zzipcode5 digitsZIP code.
zcredittextoptional Consumer-stated credit standing, if you collect it.

Worked example

{BASE_URL}?mid=1234&affid=5678&zfname=Alex&zlastname=Smith&zphone=6238805511&zemail=alex%40gmail.com&zstreet=1401+Candlewood+Dr&zcity=Pittsburgh&zstate=PA&zzipcode=15241

Result: the consumer lands with their address already in the search box (verified and formatted), and their name, phone, and email waiting in the contact form to confirm.

Rules

  • Only send data the consumer actually provided to you. Never fabricate, guess, or recycle values across consumers.
  • URL-encode every value. Spaces as + or %20, @ as %40.
  • Partial prepop is fine — send what you have. Address fields work best as a complete set (street + city + state + zip).
  • Do not append parameters beyond those on this page; unknown parameters are ignored and may break attribution if malformed.
  • Links must carry your assigned mid and affid exactly as provided — attribution and payout depend on them.
