Link & Variable Reference internal

Every querystring variable the seller funnel and report understand, and what each one does. Publisher-facing version (prepop spec only): publisher-links.html. Base pages: landing-classic-blue.html (DR lander) · option-1-classic.html (homepage) · report-classic-blue.html (report).

Attribution publisher

Flow to the lead API untouched via the page URL (srcURL on InitNewLead). Test values: mid=56&affid=testing.
VariableWhat it does
midThe campaign / media ID we assign to the publisher ("campaign ID" and "MID" are the same thing). Required on every paid link.
affidThe affiliate / sub-source ID we assign. Required on every paid link.

Contact & address prepop publisher

Prefill the funnel from an email/SMS link. Names and address parts land in the lead record twice: the raw claim (queryString* fields) and, after the silent verification chain (Smarty → Google rescue), the verified components.
VariableWhat it does
zfname / zlastnameFirst / last name → the Full name field.
zphonePhone, 10 digits (formats itself on screen). Also prefills the SMS step's box.
zemailEmail address.
zstreet / zcity / zstate / zzipcodeAddress parts. The composed string fills the hero box instantly, then verifies silently; a verified pick becomes the two-line address chip. Missing parts are recorded as literal "null" in the queryString echoes.
zcreditOptional consumer-stated credit value → the credit field.

Funnel switches internal

Variant and feature toggles for testing — do not hand these to publishers.
VariableWhat it does
terms=exclusiveDefault consent presentation (single matched pro named in the sentence). Same as no param.
terms=maxsoldMax Sold sale model: the 6-buyer demo roster inlined in the consent sentence. DEMO switch — freezes the roster (skips the live GetContactOptInNames render) and records no opt-in contacts.
terms=inlineExplicit-consent variant: first-person terms behind a 19px checkbox, tap-anywhere box, Continue blocked until checked.
terms=inline-maxsoldThe inline checkbox with the Max Sold roster.
sms=0Skips the "Access your report anytime" (SMS) step — notes goes straight to all-set, the step rail counts 4. Also accepts off/no/false. Default: step shown.
dnc=0Hides the "Do not contact me" link on the all-set step. Also accepts off/no/false. Default: link shown.
zsv=1Street View strip inside the search card once the address verifies (lander).
v=NCache buster — GitHub Pages/browser cache runs ~10 min; bump N while iterating. No functional effect.

Z-beat loading widget (z-beat-tap.html) internal

The interactive Z-beat loading indicator — self-contained single file, hold for status, double-tap to recolor. Developer guide: z-beat-tap-docs.md.
VariableWhat it does
msg=Please+waitOverrides the press-cycle messages. | separates cycle steps, ~ becomes a line break inside a message (e.g. msg=Loading|Still working~on it). Empty/missing = the six defaults. Limited stencil charset — see the guide.

Screenshot harness (shots/harness.html) internal

Drives the funnel for headless screenshots and assertions.
VariableWhat it does
src=<encoded URL>Page to load in the iframe (encodeURIComponent the whole thing, params included).
step=contact · err · questions · qerr · textreport · allset · dnc · sms · finale · ac · acfocus · acpick · clearx · clearx2 · dr · spdrag · pulse (pulse = full live-API E2E with call-log overlay).
check=1Ticks the inline consent box (needed to get past contact under terms=inline*).
slide=0-5Repairs slider level on the questions step.
scroll=N|maxScrolls the modal overlay (mobile legal-rail shots).
